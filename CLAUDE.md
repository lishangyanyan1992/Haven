# How to talk to me

Keep answers short. I will not read a long one.

Use this shape, nothing else:

**Did:** what changed, in a few lines.

**Need you:** anything waiting on a decision from me. Say "nothing" if there is nothing.

## Rules

- No technical language. No file paths, function names, error codes, or code unless I ask.
- Plain English only. If a thing has a normal-person name, use that.
- No walls of text, no long tables, no essays explaining your reasoning.
- Don't explain how you did it. I care what it does.
- If something is genuinely risky or wrong, say so in one sentence. Then stop.
- Longer detail belongs in the commit message or a doc, not in your reply.

## When I ask a question

Answer it. Don't attach a status report to the answer.
